01 / retail platform

          

        

        
Inventory Command

        

          A point-of-sale and inventory system for a multi-branch retail chain. Six roles — from Administrator
          to Sales — each see only the modules they can act on, with permissions defined in the database and
          enforced on the server, backed by row-level security on every table as a second line of defence.
        

        
    
          
  • Every stock-changing operation — sales, PO receiving, branch transfers — runs as an atomic PostgreSQL function writing to a stock-movement ledger.
    • 
          
  • A Gemini assistant grounded in read-only, branch-scoped database tools: it answers from real figures instead of generating them, and degrades to a clean 503 without an API key.
    • 
        

        
React · Vite · Express · Supabase · PostgreSQL · PL/pgSQL · Gemini

02 / social platform

          

        

        
Reddit Replica

        

          A full Reddit clone: communities, arbitrarily nested comment threads, voting, karma, direct
          messaging, custom feeds and full-text search. The backend exposes 61 endpoints across 8 modules
          and runs either as a long-lived Node process or a Vercel serverless function from the same entry point.
        

        
    
          
  • Local credentials with bcrypt alongside Google OAuth 2.0, JWT sessions, and password reset over email.

  • Messaging and notifications refresh on a visibility-aware polling interval rather than WebSockets — updates pause entirely while the tab is hidden.

05 / graph algorithms

          

        

        
Social Sphere

        

          A social-network simulator whose friend recommendations rank candidates out of a priority queue —
          scoring by traversal depth first, then by mutual-friend frequency at depth two — over an adjacency
          list walked with BFS/DFS. Graphviz renders the network for debugging large graphs.
        

        
C++ · Graphs · BFS/DFS · Priority queues · Graphviz

        

          Source
        

      


      
      

        

          
        

        

          
06 / machine learning

          

        

        
MNIST From Scratch

        

          Logistic regression, k-nearest neighbours and a linear SVM implemented without a modelling library,
          across binary and 10-class MNIST. Phase two adds One-vs-Rest with L1/L2/ElasticNet regularisation,
          PCA and HOG features, bias-variance analysis and cross-validated hyperparameter tuning.
        

        
Python · NumPy · Jupyter · PCA · HOG · SVM

        

          Source
        

      


      
      

        

          
        

        

          
07 / image processing

          

        

        
Jigsaw Puzzle Solver

        

          Reassembles shuffled square puzzles end to end: Sobel gradient analysis detects the grid size
          (2×2, 4×4, 8×8), per-piece features are extracted, and size-specific solvers use RGB seam matching
          with beam search and a refinement pass to reconstruct the image.
        

        
Python · OpenCV · NumPy · SciPy · Beam search · Tkinter GUI

        

          Source
